## About the Project

This website serves as the online presence for **Penelope Tyawa**, a registered psychologist (Pr.Nos. 8634688). With over 30 years of experience in psychology, leadership, and public service—including roles such as Acting Director General and CEO of South Africa’s Parliament—Penelope brings a unique blend of clinical expertise and strategic insight to her practice.

The site is designed to:
- **Introduce the practice** and its philosophy of providing a safe, judgment-free environment.
- **Detail the range of services** offered, from individual therapy to organisational workshops.
- **Showcase client testimonials** to build trust and demonstrate real-world impact.
- **Provide clear contact and booking information** for online and face-to-face sessions.

## Services Overview

The practice offers a comprehensive suite of psychological services tailored to individuals, schools, and organisations:

## Getting Started

This is a static website. To run it locally, you only need a modern web browser. However, if you wish to contribute to the code, follow the steps below.

### Prerequisites

- A code editor (e.g., VS Code, Sublime Text).
- A web browser (Chrome, Firefox, Safari, etc.).
- (Optional) A local development server such as [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for auto-reloading.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/sekma-n/pntsychologist.co.za.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd pntsychologist.co.za
    ```
3.  **Open the site:**
    Simply open `Home.html` in your browser. For a better development experience, right-click `Home.html` in your editor and select **"Open with Live Server"** (if installed).

## Project Structure

The project is a single-page application contained within one HTML file for simplicity and ease of deployment.

```
pntsychologist.co.za/
├── Home.html          # The main (and only) page of the website
└── README.md          # This file
```

- **`Home.html`**: Contains the complete structure, styling (via Tailwind CSS and custom CSS), and interactivity (via Bootstrap and Lucide icons) for the website.

## Technologies Used

The website leverages modern front-end technologies for a responsive, fast, and visually appealing experience.

- **Tailwind CSS** – A utility-first CSS framework for rapid UI development.
- **Bootstrap 5** – Used specifically for the client testimonial carousel.
- **Google Fonts** – Montserrat and Open Sans for typography.
- **Font Awesome** – Icon library for visual elements.
- **Lucide** – A clean, modern icon set.
- **GitHub Pages** – Hosting platform for the live site.
